# Langya-Ge-CS
**An archive of core Computer Science knowledge, fundamentals, and code.**

Welcome to Langya-Ge-CS, a structured personal repository by XiaoHeiMao serving as a comprehensive learning archive and technical interview preparation hub. Built primarily using Python and Jupyter Notebooks, this repository progresses from fundamental language mechanics to advanced data structures and algorithmic patterns.

## 🗂️ Curriculum & Structure

The repository is divided into three main progressive tracks:

### 1. Python Basics (`/Python_Basics`)
Foundational Python concepts and object-oriented programming (OOP) principles. 
* **Highlights:** Comprehensive syntax reference guides and terminal-based projects, including an OOP Blackjack capstone.

### 2. DSA Fundamentals (`/DSA_Fundamentals`)
Structured deep dives into core Computer Science algorithms and data structures. This section emphasizes engineering best practices, explicit Big O complexity analysis, and test-case-driven code.
* **Topics Covered:** Binary Search, Linked Lists, Trees & Hash Tables, Sorting & Divide-and-Conquer, Dynamic Programming, and Graph Algorithms (BFS, DFS, Dijkstra).

### 3. Algorithmic Patterns (`/algorithmic_patterns`)
A targeted technical interview preparation library organized by standard algorithmic patterns (Arrays, Two Pointers, Sliding Window, DP, Trees, etc.). 
* **Highlights:** Features an extensive Big O reference guide and documents the step-by-step thought processes, brute-force strategies, and optimized Python solutions for 40 core LeetCode problems. 

## 🛠️ Tech Stack & Formatting
* **Language:** Python
* **Format:** Jupyter Notebooks (`.ipynb`)
