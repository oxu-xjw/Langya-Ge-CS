# Langya-Ge-CS
**An archive of core Computer Science knowledge, fundamentals, and code.**

This repository is a personal study archive. It is starting with the basics and will expand to include a wider variety of Computer Science topics over time.

## 🗂️ Current Contents

### 1. Python Basics (`/python_basics`)
Fundamental Python syntax and object-oriented programming (OOP). Includes reference guides and interactive projects like Rock Paper Scissors and Blackjack.

### 2. DSA Fundamentals (`/dsa_fundamentals`)
Structured notes and code for data structures and algorithms. 
* **Topics:** Binary Search, Linked Lists, Trees, Hash Tables, Sorting, Dynamic Programming, and Graph Algorithms. 
* Includes Big O complexity analysis and test-case-driven code.

### 3. Algorithmic Patterns (`/algorithmic_patterns`)
A library of coding problems organized by algorithmic patterns (e.g., Arrays, Two Pointers, Sliding Window, Trees). 
* Includes a Big O notation reference, problem definitions, and Python solutions.

## 🛠️ Tech Stack
* **Language:** Python
* **Format:** Jupyter Notebooks (`.ipynb`)
